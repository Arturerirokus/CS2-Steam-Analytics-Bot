# 🚀 CS2 & Steam Analytics Telegram Bot

Профессиональный Telegram-бот для анализа профилей Steam, инвентаря CS2 и киберспортивной статистики FACEIT. Написан на асинхронном фреймворке `aiogram` с динамической генерацией графиков (`matplotlib`).

---

## 📂 Структура проекта
* **`main.py`** — основная логика бота, хендлеры, интеграция с API и рендеринг графиков.
* **`requirements.txt`** — список необходимых библиотек Python.
* **`.env`** — файл конфигурации с токенами (не включается в репозиторий ради безопасности).
* **`.gitignore`** — правила исключения системных файлов и кэша для Git.

---

## 💾 Куда деваются данные пользователя?
Бот спроектирован по принципу *Stateless* (без сохранения в базу данных):
* Персональные данные игроков, история матчей и инвентарь **не сохраняются** на постоянной основе в файлы или БД.
* Все запросы выполняются «на лету» в реальном времени через официальные открытые API (Steam Web, FACEIT v4, Market CSGO).
* Изображения графиков рендерятся в оперативную память (`io.BytesIO`) и сразу отправляются пользователю в чат.
